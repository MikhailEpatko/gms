# 3: Документы под JSON-вывод

**What to build:** Документация репозитория описывает JSON-вывод как фактическое поведение. README — источник правды: разделы запуска и ошибок описывают формат отчёта (массив объектов, плавающая схема, `error` как слот состояния, коды выхода), служебные JSON-объекты и примеры разбора через `jq`. Новый ADR 0006 фиксирует выбор JSON как единственного формата вывода с причинами и отвергнутыми альтернативами. Из глоссария удалён термин «Пометка». Стандарты кодирования описывают слой вывода как сборку JSON-документов, а не текст с выравниванием.

**Blocked by:** 1 (JSON-отчёт по парам и гибель пометки), 2 (JSON-служебные сообщения)

**Status:** ready-for-agent

- [ ] README описывает формат отчёта и все состояния пары примерами, коды выхода и потоки прежние, есть примеры `jq`-разбора
- [ ] README описывает служебные объекты: справка, путь к конфигу, ошибки использования и выполнения
- [ ] ADR 0006 записан: единственный формат — JSON, почему нет текстового режима и флага выбора, плавающая схема, `error` состояния, отвергнутые альтернативы
- [ ] В глоссарии нет термина «Пометка», остальные термины согласованы с поведением
- [ ] Стандарты кодирования описывают слой вывода как единственное место сборки JSON для пользователя
- [ ] `scripts/check.sh` зелёный, включая проверку защиты от секретов на новых текстах
