# 1: JSON-отчёт по парам и гибель пометки

**What to build:** `gms` без флагов и с `-p`/`-e` печатает отчёт JSON-документом: плоский массив объектов, один объект на выводимую пару, в порядке вывода (конфиг, с выборками — порядок аргументов). У каждого объекта `project` и `environment`; при наличии деплоя — `deployed_at` (RFC 3339, локальная зона), `version`, `commit` (короткий SHA), `title`; неизвестное опущено (`omitempty`). Поле `error` — единый слот состояния: текст сбоя пары или версии (прежние тексты, со строчной) либо `Нет деплоев` (с заглавной). Документ с отступами в два пробела, HTML-символы в строках не экранированы, в конце перевод строки. Пометка исчезает как понятие: запрос деплоев больше не запрашивает `ref`, модель деплоя теряет это поле, разбор `refs/merge-requests/` и формирование пометки удалены. Потоки, коды выхода, пачки и параллельность без изменений.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Отчёт по парам из конфига — валидный JSON-массив объектов; порядок объектов совпадает с порядком вывода; тесты наблюдают stdout целиком, ожидания записаны литералами, зона в тестах фиксирована
- [ ] Пара с деплоем: `project`, `environment`, `deployed_at` в RFC 3339 со смещением зоны, `version`, `commit`, `title` заполнены
- [ ] Окружение без деплоев: объект только с `project`, `environment` и `error: "Нет деплоев"`, код выхода `0`
- [ ] Ошибка пары: `project`, `environment` и `error` с прежним текстом причины, деплой-поля отсутствуют, код выхода `1`
- [ ] Ошибка версии: `deployed_at`, `commit`, `title` на месте, `version` отсутствует, `error` с прежним текстом причины, код выхода `1`
- [ ] Тесты выборок `-p`/`-e` наблюдают JSON-отчёт с прежними порядком и составом пар
- [ ] Контрактные тесты пачек и состава запрошенных пар зелёные: запросы не меняются, кроме исчезнувшего поля `ref`
- [ ] Отсутствуют разбор `refs/merge-requests/` и любое упоминание пометки в коде
- [ ] Документ с отступами в два пробела, заканчивается переводом строки; заголовки коммитов с `<`, `>`, `&` не экранированы
- [ ] `scripts/check.sh` зелёный
