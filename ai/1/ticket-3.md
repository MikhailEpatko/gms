# 3: Пометки текущего деплоя и «нет деплоев»

**What to build:** если текущий деплой окружения сделан не из ветки окружения, это видно в строке даты. Деплой из MR помечается `(MR !<N>)`, деплой из любой другой чужой ветки помечается `(ветка: <ref>)`. Окружение без единого успешного деплоя выводит `нет деплоев` вместо трёх строк. Термины **Текущий деплой** и **Ветка окружения** см. в `GLOSSARY.md`. Спека: `ai/1/spec.md`, user stories 25–29.
