# 2: Несколько проектов и разбор `-p`

**What to build:** `gms` без флагов выводит все проекты из конфига в порядке файла. `gms -p project1,project2` выводит только перечисленные проекты в порядке аргументов. Блоки проектов разделены двумя пустыми строками и линией из 63 знаков `=`. Спека: `ai/1/spec.md`, user stories 1–8, 34–36.

**Blocked by:** 1 (Текущий деплой одного проекта: от конфига до вывода)

**Status:** done

- [x] `gms` без флагов выводит все проекты в порядке конфига.
- [x] `-p project2,project1` выводит сначала `project2`, затем `project1`.
- [x] Пробелы вокруг кодов обрезаются: `-p "project1, project2"` работает как `-p project1,project2`.
- [x] Пустые элементы пропускаются: `-p project1,,project2` и `-p project1,` работают.
- [x] Повторный флаг накапливает коды: `-p project1 -p project2` = `-p project1,project2`.
- [x] Повторы кода схлопываются по первому вхождению: `-p project1,project2,project1` выводит `project1`, затем `project2`, каждый один раз.
- [x] Между проектами: две пустые строки и линия из 63 знаков `=`, вплотную к коду следующего проекта. Перед первым проектом и после последнего разделителя нет.
- [x] Все проверки идут через `Run` с фейковым runner. `go test ./...` проходит.
