# 2: Go-код без комментариев

**What to build:** в `main.go` и пакете `internal/gms`, включая тесты, нет ни одного комментария, а поведение `gms` не изменилось. Знание из каждого комментария уходит по порядку ADR 0005:
- doc-комментарий, пересказывающий сигнатуру, удаляется без замены;
- смысл комментария к переменной, полю или маркеру переходит в имя: переименование, именованные константы для пустых строк-маркеров фейкового GitLab («любой хост», «окружение без деплоев»);
- неочевидное «почему» сверяется с ADR 0001–0004 и README. Если там уже есть, комментарий просто удаляется. Если нет, решение дописывается в ADR, поведение для пользователя — в README, остальное удаляется.

Описание заготовок ответов GitLab переезжает в README рядом с ними: дата съёмки реальных ответов, общий коммит деплоя у project2 и разные у project1, из какой заготовки и какой правкой собрана каждая синтетическая. Правила ревью, которые говорили о комментариях в Go, переписываются. Спека: `ai/10/spec.md`, user stories 26–30, 40, 41, 45, 47.
