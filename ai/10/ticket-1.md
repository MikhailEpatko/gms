# 1: Программа проверки комментариев

**What to build:** программа на Go без сторонних зависимостей, которая обходит репозиторий и печатает каждый комментарий в коде: в Go-файлах (включая тесты), shell-скриптах, файлах pre-commit hook и TOML. Каждая находка печатается строкой `<путь>:<строка>: <текст>`, последней строкой идёт подсказка со ссылкой на ADR 0005, код выхода 1. Без находок программа молчит и возвращает 0. Директивы инструментов, shebang в первой строке, `//` в строковых литералах, `$#` и всё в `.claude/` и `.git/` находками не считаются. Программа сама обходит дерево и не зависит от git, поэтому работает и в копии индекса из hook. `scripts/check.sh` её пока не вызывает: код ещё не чист. Спека: `ai/10/spec.md`, user stories 1–25, 42.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Запуск программы на репозитории перечисляет текущие комментарии из `main.go`, `internal/gms`, `scripts/*.sh`, `.githooks/pre-commit` и `.gitleaks.toml`, завершается подсказкой и кодом 1. В выводе нет файлов из `.claude/`, Markdown и заготовок `testdata/`, а `https://…` из raw-строк тестовых конфигов в выводе не встречается.
- [x] Go: строчный, хвостовой, блочный однострочный и многострочный комментарии (для многострочного печатается первая строка), а также комментарий в `_test.go` дают находки. `//go:build`, `//nolint:…` и комментарий, равный ровно `gitleaks:allow`, находок не дают. `// gitleaks:allow`, `//nolint:… // причина` и `//go:build … // текст` с пояснением дают находку. `//` и `/*` внутри обычной и raw-строки находок не дают.
- [x] Shell: строка, начинающаяся с `#`, в том числе после отступа, даёт находку. Shebang в первой строке не даёт, `#!` во второй строке даёт. `$#`, `${#x}` и `echo "#"` не дают. Хвостовой `cmd # текст` не даёт: это граница программы, её закрепляет тест.
- [x] Файл в `.githooks/` без расширения проверяется как shell. Строка `*.toml`, начинающаяся с `#`, даёт находку.
- [x] Находки нескольких файлов идут в порядке обхода дерева (записи каталога по имени, поэтому `a/b.sh` раньше `a.toml`), внутри файла — по строке. Путь печатается через `/` от корня. Подсказка печатается один раз, последней строкой.
- [x] Если файл не удалось прочитать, программа печатает строку с путём и ошибкой и завершается с кодом 1.
- [x] Тесты табличные, на стандартном `testing`. Они вызывают `run(fs.FS, io.Writer) int` с `fstest.MapFS` и сверяют только stdout и код выхода, ожидаемый вывод записан литералом.
- [x] В выводе программы нет её собственных файлов, `go vet` и `go test -race` из `scripts/check.sh` проходят и для неё.
- [x] В `CODING_STANDARDS.md` правило «Один seam» различает seam `internal/gms` (`Run`) и seam программы проверки (`run` с `fstest.MapFS`). Если детали ADR 0005 разошлись с реализацией (формат вывода, список директив), ADR поправлен на месте.
