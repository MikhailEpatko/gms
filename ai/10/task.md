Задача 10:

Нужно убрать комментарии из кода и не давать им появляться снова: правило для разработки и ревью плюс проверка в
`scripts/check.sh`.

Зачем: см. ADR 0005. Комментарий устаревает молча, дублирует README и ADR, а агент подражает плотности комментариев
вокруг.

Решено на `/grill-with-docs` (2026-10-31):
- Код — это Go (включая тесты), shell-скрипты, `.githooks/pre-commit` и `.gitleaks.toml`. Разрешены только директивы
  `//go:`, `//nolint`, `gitleaks:allow` и shebang в первой строке. README с `#` в примерах команд и `.claude/` правило не
  затрагивает.
- Существующие комментарии (около 150 строк в Go, около 40 в скриптах и hook, шапка `.gitleaks.toml`) удаляются в этой
  задаче. Знание из комментария уходит в первое подходящее место по порядку из ADR 0005: имя, тест через `Run` (новые
  тесты в задаче не пишутся), ADR или README, `internal/gms/testdata/README.md`, иначе удаляется.
- Проверка — своя программа `scripts/nocomments` (пакет `main` в модуле), `check.sh` вызывает `go run ./scripts/nocomments`.
  Go разбирается `go/scanner`, в shell и TOML ловятся строки, где первый непробельный символ `#`. Программа сама обходит
  дерево и пропускает `.git/` и `.claude/`, поэтому работает и в копии индекса из hook.
- Seam тестов программы: `run(fsys fs.FS, stdout io.Writer) int`, `main` передаёт `os.DirFS(".")`. Тесты на `fstest.MapFS`
  сверяют stdout и код выхода, ожидаемый вывод записан литералом. Находка печатается строкой
  `<путь>:<строка>: <текст комментария>`, в конце подсказка со ссылкой на ADR 0005 и код 1; без находок — тишина и код 0.
- Правило для разработки: `.claude/rules/no-comments.md` с `paths` на `**/*.go`, `scripts/**`, `.githooks/**`, `*.toml`.
  В `AGENTS.md` одна строка о новой проверке в `check.sh`.
- Правило для ревью: раздел «Комментарии» в `CODING_STANDARDS.md` (хвостовой `cmd # текст` в shell, куда ушло знание).
  Переписываются «Комментарии … пишутся на русском» в «Язык», «комментарий к их map» в «Тесты» и «Один seam» (в
  `internal/gms` — `Run`, в `scripts/nocomments` — `run`).
- Heredoc в `scripts/check-secrets.sh:181`: shebang заглушки выводится отдельной командой
  (`{ echo '#!/bin/sh'; cat <<'EOF'; } >файл`).
- `check.sh` начинает вызывать проверку только тогда, когда код уже чист, иначе hook остановит промежуточные коммиты.
