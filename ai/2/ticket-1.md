# 1: Фильтр окружений `-e`

**What to build:** `gms -e DEV,DEMO` выводит все проекты, но у каждого только окружения DEV и DEMO. `gms -e PROD -p project1` выводит одно окружение одного проекта. Имена окружений сравниваются без учёта регистра, окружения идут в порядке аргументов `-e`, в выводе имя пишется так, как в конфиге. Пары, которой нет в конфиге, нет и в выводе, а проект без нужных окружений не выводится вовсе. В GitLab запрашиваются только выведенные пары. Значение `-e` разбирается по правилам `-p`. Спека: `ai/2/spec.md`, user stories 1–14, 19–20, 23–26, 31–33.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] `gms -e DEV,DEMO` выводит все проекты в прежнем порядке, у каждого только DEV, затем DEMO.
- [x] `gms -e PROD -p project1` выводит только `project1` и у него только PROD.
- [x] `-e prod,demo` выводит окружения с заголовками `PROD:` и `DEMO:` в написании из конфига.
- [x] `-e PROD,DEV` выводит внутри проекта сначала PROD, затем DEV. Без `-e` окружения по-прежнему выводятся все и в порядке конфига.
- [x] С `-e` проекты выводятся в порядке `-p`, а без `-p` в порядке конфига.
- [x] Пробелы вокруг имён обрезаются, пустые элементы пропускаются: `-e " DEV , DEMO "`, `-e DEV,,DEMO` и `-e DEV,` работают.
- [x] Повторный флаг накапливает имена: `-e DEV -e PROD` = `-e DEV,PROD`.
- [x] Повторы схлопываются по первому вхождению без учёта регистра: `-e dev,DEMO,DEV` выводит DEV, затем DEMO, каждое по одному разу.
- [x] `-e ""` и `-e ,` дают в stderr `gms: в -e не указано ни одно окружение, пример: -e DEV,DEMO`, exit 2, пустой stdout, без вызовов `glab`.
- [x] Если у одного проекта есть окружение из `-e`, а у другого нет, второй проект не выводится, и в выводе нет ни заголовка проекта, ни лишних разделителей.
- [x] Разделители окружений и проектов стоят только между выведенными блоками.
- [x] Запросы деплоев к GitLab содержат только окружения выведенных пар: `gms -e PROD` на конфиге с DEV, DEMO и PROD не запрашивает `dev` и `demo`.
- [x] Ошибка пары при `-e` выводится на месте этой пары, остальные пары выводятся, exit 1.
- [x] `gms -e DEV -c` печатает путь к конфигу и выходит без запросов к GitLab.
- [x] `-e` принимает записи `-e DEV`, `-e=DEV` и `--e DEV`.
- [x] Справка `gms -h` содержит `[-e имя,имя]` в строке использования и строку `-e имя,имя  только перечисленные окружения, в порядке аргументов, регистр не важен`.
- [x] В `README.md` и `CLAUDE.md` описан `-e` в разделах о запуске.
- [x] Все проверки идут через `Run` с фейковым `glab`. `scripts/check.sh` проходит.
