Задача 7:

Нужен компактный вывод: одна строка на пару проект+окружение.

Зачем: сейчас каждая пара занимает 4 строки, а между ними стоят разделители окружений и проектов. Для 4 проектов
по 3 окружения вывод занимает до 77 строк и не помещается в экран. Сравнить, например, версии PROD у разных проектов
можно только прокруткой.

Набросок, не решение:
```
project1  DEV   2026-09-24 16:35:33 MSK  7.0.2   1abfac4b Merge branch 'XXXXX-3488' into 'dev' (MR !23)
project1  DEMO  нет деплоев
```

Что известно:
- Текст для пользователя собирается только в `format.go` (CODING_STANDARDS.md).
- Выровнять колонки можно стандартной библиотекой (`text/tabwriter`), сторонние зависимости не нужны.
- В спеках задач 1 и 2 изменение формата вывода было вне рамок, так что это новое решение.
- В тестах ожидаемый вывод записывается литералом.

Открытые вопросы:
- Включается флагом (каким) или становится форматом по умолчанию.
- Набор и порядок колонок, нужна ли строка заголовка, повторяется ли код проекта в каждой строке.
- Куда ставятся пометки `(MR !N)` и `(ветка: X)`.
- Как выглядят в одну строку «нет деплоев», ошибка пары и ошибка версии.
- Обрезать ли заголовок коммита по ширине терминала.
- Как новый формат сочетается с `-p`, `-e`, `-c` и справкой `-h`.
