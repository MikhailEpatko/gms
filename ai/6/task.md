Задача 6:

Нужно убрать дублирование описания поведения `gms` между `README.md` и `CLAUDE.md`.

Зачем: разделы README «Запуск», «Конфиг», «Откуда берутся данные», «Ошибки» и раздел CLAUDE.md «Что делает утилита
`gms`» — это одни и те же ~50 строк. Каждую фичу приходится вписывать в оба файла (спека `ai/2/spec.md` так и
требовала), и копии уже разошлись:
- в примере вывода README идёт `project1`, затем `project2`, а в CLAUDE.md наоборот;
- абзац про конфиг сформулирован по-разному, и только в CLAUDE.md сказано, что пример конфига обезличен
  (`gitlab.example.com`) и что exit ≠ 0;
- в примере вывода README стоит версия `7.0.2`, а в комментарии к ней `build_version=1.0.2`.

Предложение: README остаётся единственным описанием поведения, а CLAUDE.md подключает его импортом `@README.md`
(Claude Code подтягивает импортированный файл в контекст) или ссылается на него и оставляет только то, что нужно
агенту: состояние проекта, команды, процесс работы, skills.

Открытые вопросы:
- Импорт или ссылка. Импорт вместе с поведением тянет в контекст агента ~90 строк инструкций по установке.
- Что ещё в CLAUDE.md повторяет другие файлы (ADR, `ai/*/spec.md`) и что из этого оставить.
- Ссылка CODING_STANDARDS.md на «правило README.md» должна остаться верной.
