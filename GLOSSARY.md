# gms

Утилита показывает, что сейчас развёрнуто на каждом окружении каждого проекта.

## Language

### Проекты и окружения

**Проект**:
Приложение с собственным репозиторием в GitLab, обозначаемое коротким кодом (`project1`, `project2` и т.д.).
_Avoid_: сервис, репозиторий, коннектор

**Код проекта**:
Короткое имя проекта, под которым он указан в конфиге и в аргументах `-p`.
_Avoid_: алиас, ключ

**Окружение**:
Отдельный работающий экземпляр проекта, на который его деплоят: DEV, DEMO, PROD. У каждого проекта свои окружения, а одноимённые окружения разных проектов связывает только имя окружения.
_Avoid_: стенд, среда, environment

**Имя окружения**:
Имя, под которым окружение указано в конфиге и в аргументах `-e` (DEV, DEMO, PROD). Регистр не различается: `dev` и `DEV` — одно окружение.
_Avoid_: код окружения, ключ

**Ветка окружения**:
Ветка, из которой окружение деплоится штатно, указывается для него в конфиге (DEV ← `dev`, DEMO ← `demo`, PROD ← `main`). Текущий деплой может быть сделан из другой ветки или из MR.
_Avoid_: целевая ветка

**Пара**:
Проект вместе с одним из его окружений, для которых `gms` показывает один текущий деплой.
_Avoid_: связка, комбинация

### Деплой

**Деплой**:
Успешное развёртывание конкретного коммита проекта на окружение.
_Avoid_: релиз, выкладка, deployment

**Текущий деплой**:
Последний успешный деплой на окружение, из какой бы ветки или MR он ни был сделан. Отражает то, что реально работает на окружении.
_Avoid_: последний деплой ветки

**Дата деплоя**:
Момент завершения деплоя.
_Avoid_: дата релиза, LAST DEPLOYED

**Коммит деплоя**:
Коммит, который был развёрнут деплоем.
_Avoid_: последний коммит ветки, HEAD

**Версия приложения**:
Значение `build_version` из файла `application.version` на коммите деплоя.
_Avoid_: версия релиза, ревизия, REVISION

### Ошибки

**Ошибка пары**:
Сбой, из-за которого неизвестен текущий деплой пары. Окружение без деплоев ошибкой пары не считается.
_Avoid_: ошибка проекта, ошибка окружения

**Ошибка версии**:
Сбой, из-за которого неизвестна только версия приложения, а дата и коммит деплоя известны.
_Avoid_: ошибка пары
