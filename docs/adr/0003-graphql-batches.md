# GraphQL пачками вместо REST-запроса на пару

Сначала `gms` запускал `glab` 25 раз на 12 пар: `glab auth status`, затем Deployments API и `application.version` по REST на каждую пару. Запуск `glab` оказался дорогим: на рабочей машине Kaspersky проверяет неподписанный бинарник `glab` (71 МБ) при каждом запуске. Один запуск занимает ~1,4 с, а 12 одновременных идут ~17 с каждый, потому что встают в очередь к антивирусу. Весь вывод занимал 46 с. Поэтому пары одного хоста запрашиваются через `glab api graphql` пачками до 8 пар, по два запроса на пачку: текущие деплои (`environment.lastDeployment(status: SUCCESS)`) и версии (`repository.blobs(ref: <sha>)`). Проверка входа встроена в первый запрос (`currentUser`), так что отдельного `glab auth status` нет. Получилось 4 запуска и 4,7 с на те же 12 пар.

## Consequences

- Размер пачки ограничен сложностью запроса: GitLab отклоняет запросы сложнее 250, а пачка из 8 пар стоит 101 (деплои) и 115 (версии) по замеру 2026-10-18.
- Ошибка вызова `glab` (сеть, HTTP, ошибка GraphQL) становится ошибкой всех пар пачки, а не одной пары: glab завершается с ошибкой даже при частичной ошибке GraphQL.
- GraphQL отвечает `null` и на несуществующий проект, и на проект без доступа, поэтому их не различить. Без входа GraphQL работает анонимно, и отсутствие входа видно только по `currentUser: null`.
- Подсказку входа `gms` даёт только при `currentUser: null`. Остальные сбои выводятся как ошибка каждой пары пачки, без подсказки и с exit 1:
  - Истёкший или отозванный токен: GitLab отвечает HTTP 401, glab завершается с ошибкой, и в строке пары видна причина от glab.
  - Сбой сети или прокси: например `EOF`, когда `HTTPS_PROXY` не пропускает трафик к GitLab. Раньше такой сбой ловил `glab auth status`, и `gms` выходил с подсказкой входа, хотя дело было не во входе.

  Отдельная проверка входа вернула бы лишний запуск `glab`, поэтому от неё отказались.
- Результат `lastDeployment(status: SUCCESS)` совпал с REST `order_by=finished_at` на всех 12 парах 2026-10-18.

## Considered Options

- Выводить проекты по мере готовности: отклонено, после перехода на пачки все пары хоста приходят одним ответом.
- Брать токен у `glab` один раз и ходить в API своим HTTP-клиентом: противоречит ADR 0001.
- Исключить `glab` из проверки антивирусом: нужен администратор, и это решает проблему только на одной машине.
