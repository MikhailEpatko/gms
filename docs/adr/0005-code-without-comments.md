# Код без комментариев

В Go, shell-скриптах, pre-commit hook и `.gitleaks.toml` комментариев нет. Комментарий устаревает молча: его не проверяют ни компилятор, ни тесты, а в этом репозитории он к тому же дублировал README и ADR (лимит сложности 250, антивирус, форматы ref у MR). Агент, который пишет код, подражает плотности комментариев вокруг, поэтому их становилось только больше. Знание, которое должно жить, живёт там, где его проверяют (имя, тест), или там, где его ищут (ADR, README). Отсутствие комментариев проверяет своя программа `nocomments` на Go, её вызывает `scripts/check.sh`. Она живёт в отдельном публичном репозитории `github.com/MikhailEpatko/nocomments`, чтобы её можно было ставить в другие проекты, а модуль gms содержал только gms.

Знание из комментария уходит в первое подходящее место:

1. Имя: идентификатор, константа или функция говорят сами за себя. Doc-комментарий, который пересказывает сигнатуру, удаляется без замены.
2. Тест, имя которого называет причину неочевидного поведения: через `Run` для `gms`, случай в `scripts/check-secrets.sh` для скриптов, hook и `.gitleaks.toml`.
3. ADR для решения с выбором, README для поведения, видимого пользователю, `CODING_STANDARDS.md` для правила, как писать код или тесты.
4. `internal/gms/testdata/README.md` для заготовок ответов GitLab: дата съёмки и из чего собраны синтетические.
5. Остальное удаляется, контекст остаётся в сообщении коммита.

## Consequences

- Разрешены только директивы инструментов без пояснений: `//go:…` и `//nolint…`, в которых нет ` //`, `// gitleaks:allow` и shebang в первой строке shell-скрипта. Текст сразу после `//go:` (`//go:это комментарий`) программа принимает за директиву, его ловит ревьюер.
- В Go программа находит любой `//` и `/* */` вне строковых литералов (`go/scanner`). В shell и TOML она видит только строки, где первый непробельный символ `#`: хвостовой `cmd # текст` без парсера не отличить от `$#` и `${#x}`, его ловит ревьюер по `CODING_STANDARDS.md`.
- Heredoc программа не разбирает, поэтому строка данных в нём не начинается с `#`: shebang для файла, который пишет скрипт, выводится отдельной командой (`{ echo '#!/bin/sh'; cat <<'EOF'; } >файл`). Так же и в TOML строка многострочного литерала не начинается с `#`.
- `check.sh` вызывает установленный `nocomments` после `gofmt` и до `go vet`, а если его нет в `PATH`, останавливается с командой `go install github.com/MikhailEpatko/nocomments@latest`. Ставят его каждый, кто коммитит, и CI, как gitleaks (ADR 0004). Запуск бинарника на рабочей машине стоит ~0,02 с (первый запуск после установки ~0,8 с), в копии индекса из hook столько же.
- Версия nocomments не закрепляется: правка в nocomments доходит до gms без правки gms, но может и покраснить `check.sh` у всех, кто переустановил программу.
- `go doc` не показывает описаний пакета и функций.
- В golangci-lint (задача 5) выключаются линтеры, которые требуют doc-комментарии: `revive` (`exported`, `package-comments`) и `stylecheck` (ST1000, ST1020–ST1022). `nolintlint` включается без `require-explanation`: пояснение `//nolint:x // причина` — комментарий.

## Considered Options

- ast-grep: правило `kind: comment` по дереву tree-sitter закрывает Go и shell полностью, включая хвостовые `#`. Отклонён: бинарник на Rust ставится не через `go install`, а отдельным менеджером пакетов, и `.gitleaks.toml` он всё равно не разбирает.
- Плагин golangci-lint: готового линтера, запрещающего комментарии, нет (`godox` ловит только слова вроде TODO, `godot` проверяет оформление), свой анализатор тянет сборку кастомного golangci-lint.
- Только текст правила для ревьюера: отклонён, правило механическое, и агент узнавал бы о нарушении на ревью, а не из `check.sh`.
- Правило только для нового diff: отклонено, смешанный код учит агента писать комментарии рядом со старыми.
- `go run ./scripts/nocomments` внутри модуля gms (первое решение задачи 10): ставить ничего не нужно, но программу нельзя переиспользовать в других проектах, а `go run` стоит ~1,3 с на каждом `check.sh` и ~2,5 с в копии индекса из hook, где пакет собирается заново (`-trimpath` сокращал это до ~1,4 с ценой пересборки стандартной библиотеки, ~12 с на каждой машине). Отклонён при выносе программы в отдельный репозиторий.
